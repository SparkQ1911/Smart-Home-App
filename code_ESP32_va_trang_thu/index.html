Trang thử MQTT cũ đã ngừng hoạt động

Trang này từng kết nối broker MQTT công khai không xác thực, không phù hợp để điều khiển ESP32 thật. Hãy dùng ứng dụng Smart Home qua REST API; server bridge và ESP32 kết nối Adafruit IO qua TLS.

Không đưa AIO Key hoặc thông tin Wi-Fi vào trang web tĩnh. Hãy cấu hình chúng riêng trong secrets của server và file machine_config.py trên ESP32.
